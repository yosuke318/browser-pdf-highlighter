# 正規化の規則(全書類共通)

抽出した文字列を、比較や差分検出ができる形に揃えるための規則。
正規化は比較用の値を作るためのもので、画面には元の文字列(`rawText`)も残す。

## 和暦 → 西暦

| 元号 | 略記 | 開始日 | 西暦 = 和暦年 + |
|---|---|---|---|
| 令和 | 令、R | 2019-05-01 | 2018 |
| 平成 | 平、H | 1989-01-08 | 1988 |
| 昭和 | 昭、S | 1926-12-25 | 1925 |
| 大正 | 大、T | 1912-07-30 | 1911 |
| 明治 | 明、M | (省略) | 1867 |

- 明治生まれの人は2026年時点で113歳以上なので、生年月日の欄ではまず出てこない。
  様式に「明」の選択肢があっても、選ばれていたら読み取り誤りを疑う

- 「元年」は1年として扱う(令和元年 = 2019年)
- 元号の切り替わりの年は、日付で元号を確かめる。例: 「平成31年4月30日」と
  「令和元年5月1日」は連続する日付。「令和元年4月1日」のような存在しない日付は
  書き間違いの可能性があるので、変換したうえで注意を付ける
- 年だけの欄(「令和7年分」など)は、年の変換だけをする
- 「R7.4.1」「H8/4/15」のような略記にも対応する
- 既存の変換関数は `scripts/generate-samples/format.ts` の `toWareki`(西暦 → 和暦)。
  逆向きの変換を書くときは、同じ元号の表を使う

## 数字と金額

- 全角数字(`０-９`)は半角にする
- 区切りの「,」「,」、空白、通貨記号「¥」「¥」「円」を除く
- 単位を換算する: 「万円」は × 10,000、「千円」は × 1,000
  (「420万円」→ 4,200,000、「1,234千円」→ 1,234,000)
- 漢数字の金額(「四百二十万円」「一〇〇万円」)は手書きの書類で出ることがある。
  対応する場合は、位取り(十・百・千・万・億)を正しく扱う
- 税の書類の「△」「▲」は負の数(赤字・還付)を表す。単なる記号として捨てない
- 「※」「*」などの注記記号は、数字の前後から除く
- 金額欄の空欄と「0」と「-」(該当なし)は、区別して扱う

## 会社名

比較するときは、法人の種類を表す略記を正式名に揃える。

| 略記 | 正式名 |
|---|---|
| ㈱、(株)、(株) | 株式会社 |
| ㈲、(有)、(有) | 有限会社 |
| (同)、(同) | 合同会社 |
| ㈳、(社) | 社団法人 |
| ㈶、(財) | 財団法人 |

- 「株式会社」が前に付く(前株)か後ろに付く(後株)かで別の会社になる。
  「株式会社サンプル」と「サンプル株式会社」は同じとみなさない
- 「支店」「営業所」などの事業所名が付いている場合は、会社名と分けて扱う

## 氏名

- 姓と名の間の空白(全角・半角・なし)は、比較では無視する
- 異体字は比較では同じとみなすが、差分として「表記の違い」を表示する。
  例: 髙/高、﨑/崎、邊/邉/辺、齋/斎/斉、德/徳
- フリガナは、ひらがな/カタカナ、全角/半角カナを揃えてから比較する

## 住所

- 「1丁目2番3号」「1-2-3」「一丁目二番三号」は同じ住所として扱う
- 「ヶ」「ケ」「が」(例: 霞ヶ関/霞ケ関)は同じとみなす
- 都道府県の省略(「見本市…」と「見本県見本市…」)は、同じ住所の可能性があるが、
  自動で一致とはせず、注意を付ける
- 建物名・部屋番号の有無の違いは、差分として表示する(引っ越しの手がかりになるため)

## 差分の判定で使う考え方

- 正規化後に一致 → 「一致」(画面で表記の違いを補足してもよい)
- 正規化後も異なる → 「変更」
- どちらかが読み取れなかった → 「比較できない」として扱い、「変更」と区別する
- 差分の判定ルールは `docs/extraction-fields.md` の「4. 差分の判定ルール」にまとめている
  (2026-10-13 に利用者と合意済み)。このファイルの規則と食い違ったら、合意した内容を優先して、このファイルを直す
