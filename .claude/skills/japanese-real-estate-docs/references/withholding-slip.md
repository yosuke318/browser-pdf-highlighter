# 給与所得の源泉徴収票

会社員の年収を確認する、最も基本的な書類。様式は国税庁が定めていて、どの会社が
発行しても欄の並びはほぼ同じ。そのため座標領域指定とラベル近傍探索の両方が効く。
ただし、給与計算ソフトごとに罫線・フォント・余白の差はある。

## 書類の見分け方

- タイトル: 「給与所得の源泉徴収票」(上部中央)。前に「令和○年分」が付く
- 「(受給者交付用)」の表記がある。本人が受け取るのはこの写し
- 似た書類と取り違えない:
  - 「退職所得の源泉徴収票」: 退職金の書類。年収の確認には使わない
  - 「公的年金等の源泉徴収票」: 年金受給者の書類。欄の構成が違う
  - 「給与支払報告書」: 会社が市区町村に出す書類で、欄の構成はほぼ同じ。
    タイトルの違いで判定する

## 抽出項目

キー名は `schema/extraction-fields.json`(抽出項目の定義)に合わせている。

| キー | 欄の名前(表記ゆれ) | 型 | 位置と注意 |
|---|---|---|---|
| `incomeYear` | 「令和○年分」 | 年(西暦) | タイトルの前。和暦から変換する |
| `name` | 氏名 | text | 「支払を受ける者」の枠内。フリガナ欄と区別する |
| `address` | 住所又は居所 | text | 「支払を受ける者」の枠内。支払者の住所と取り違えない |
| `birthDate` | 受給者生年月日 | date | 下部の右側。元号・年・月・日が別のマスに分かれている |
| `employerName` | 氏名又は名称 | text | 下部の「支払者」の枠内。受給者の氏名欄と同じ文言なので、枠で区別する |
| `employerAddress` | 住所(居所)又は所在地 | text | 「支払者」の枠内 |
| `paymentAmount` | 支払金額 | money | **年収として扱う欄**。1段目の左から2番目 |
| `salaryIncomeAfterDeduction` | 給与所得控除後の金額(調整控除後) | money | 支払金額の右隣 |
| `totalDeductions` | 所得控除の額の合計額 | money | |
| `withholdingTax` | 源泉徴収税額 | money | 1段目の右端 |
| `socialInsurance` | 社会保険料等の金額 | money | 3段目の左端 |

## 読み違えやすい点

- **「内」の小さな数字。** 支払金額と源泉徴収税額の欄には、左上に小さく「内」と
  書かれたマスがある。ここに入る数字は、未払いの金額(または未徴収の税額)で、
  年収ではない。テキスト抽出では「内 1,200,000 5,800,000」のように同じ行に並ぶ
  ことがあるので、欄の右寄せの大きい数字を取る
- **ラベルが同じ「氏名」「住所」が2組ある。** 上が受給者、下が支払者(勤務先)。
  縦書きの見出し「支払を受ける者」「支払者」で領域を分ける
- **生年月日の元号。** 様式によっては「明・大・昭・平・令」を丸で囲む形式や、
  元号の欄に1文字だけ入る形式がある。元号が読み取れないときは推測せず、低い信頼度にする
- **中途就職・退職。** 「中途就・退職」欄に就職日や退職日が入っている場合、
  支払金額は1年分ではない。年収として扱う前に注意を表示する
- **乙欄。** 「乙欄」に印がある場合は副業先の源泉徴収票。主たる勤務先の年収ではない
- **摘要欄の前職分。** 年の途中で転職した人は、摘要欄に「前職分 支払金額○○円」の
  ように前の会社の金額が書かれ、支払金額に合算されていることがある。
  摘要欄の金額を年収として取らない
- **複数年分の取り違え。** 前年分と今年分を一緒に提出されることがある。
  差分比較では `incomeYear` を必ず確認する

## 電子交付のPDF(様式が画像、値だけが文字)

勤務先の給与システムが出力する電子交付の源泉徴収票には、次の形のものがある(実物で確認。
ダミーは `samples/withholding-slip/overlay.pdf`)。

- **様式(罫線・欄の名前)は画像で、値だけが見える文字として重ねてある。** 欄の名前は文字としては1つもないので、
  PDF の文字だけでは書類の種類もラベルも分からない。ページの種類 `overlay` として判別し、欄の名前は OCR で読み、
  値は PDF の文字を使う(`src/ocr/overlay.ts`)
- **欄の名前が小さく、画像の解像度も低い。** 「支払金額」「給与所得控除後の金額」「氏名」「住所又は居所」などは
  OCR で読めないことがある。金額の行は、読めた見出し(「源泉徴収税額」など)を目印に、欄の並び順で割り当てる
  (`column` ルール)。勤務先は、会社の形の名前(「株式会社」など)を PDF の文字から探す
- **金額は空白で3桁ずつ区切り、様式の「千」「円」の区切りに合わせて置く。** 先頭の桁だけが離れた別の文字列に
  なっていたり(「5」「800 000」)、「千」をはさんで離れていたりする(「870」「000」)。様式の枠の罫線を
  はさまない同じ行の数字はつなげる。金額の欄には桁の区切りを示す**短い縦線**もあるので、見出しの行まで
  伸びている線だけを枠の罫線とみなす
- A4横のページの右半分に源泉徴収票がある

## 抽出結果の検算

`paymentAmount` と `salaryIncomeAfterDeduction` には決まった関係があるので、
抽出した値の確からしさを確かめられる。給与所得控除の額は次のとおり(支払金額を A とする)。

令和7年分(2025年)以降:

| 支払金額 A | 給与所得控除 |
|---|---|
| 190万円以下 | 65万円 |
| 190万円超〜360万円以下 | A × 30% + 8万円 |
| 360万円超〜660万円以下 | A × 20% + 44万円 |
| 660万円超〜850万円以下 | A × 10% + 110万円 |
| 850万円超 | 195万円(上限) |

令和2年分〜令和6年分(2020〜2024年)は、162.5万円以下が55万円、
162.5万円超〜180万円以下が A × 40% − 10万円で、180万円超は上の表と同じ。

ただし、次の理由で完全には一致しないことがある。検算は「数万円以内の差なら妥当」
程度の確認にとどめ、一致しないことを理由に値を書き換えない。

- 支払金額が660万円未満の場合、実際の計算は国税庁の早見表(4,000円刻み)を使うため、
  式の結果と数千円ずれる
- 「所得金額調整控除」(子育て世帯や、年金も受け取る人が対象)があると、
  給与所得控除後の金額が小さくなる

例: サンプルの山田太郎は、支払金額 5,800,000円 → 控除 5,800,000 × 20% + 440,000 =
1,600,000円 → 給与所得控除後 4,200,000円で、`expected.json` と一致する。
