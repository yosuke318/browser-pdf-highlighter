# 日本の不動産書類の知識

このプロジェクトは、不動産の審査で使う個人情報入りPDFから、ルールベースで項目を
抽出する。抽出ルールを正しく書くには、書類の欄の意味と、紛らわしい欄を知っている
必要がある。このスキルはその知識をまとめたもの。

## 書類ごとの参照先

作業対象の書類に応じて、該当するファイルを読む。

| 書類 | 参照ファイル | 状態 |
|---|---|---|
| 給与所得の源泉徴収票 | [references/withholding-slip.md](references/withholding-slip.md) | 作成済み |
| 賃貸の入居申込書 | [references/rental-application.md](references/rental-application.md) | 作成済み |
| 和暦・金額・会社名・住所の正規化(全書類共通) | [references/normalization.md](references/normalization.md) | 作成済み |
| 課税証明書・所得証明書・住民税決定通知書 | (未作成) | 下の「共通の注意」を参照 |
| 住宅ローン申込書・審査書類 | (未作成) | |
| 確定申告書 | (未作成) | |

未作成の書類を扱うときは、推測で欄の意味を断定しない。様式が手元にない場合は、
`samples/` のダミーと `scripts/generate-samples/templates/` のテンプレートを見て、
分からない点はユーザーに確認する。新しく分かったことは、このスキルに書き足すよう提案する。

## 全書類に共通する注意

- **「年収」は書類ごとに意味が違う。** 源泉徴収票の「支払金額」、課税証明書の
  「給与収入」、入居申込書の自己申告の「税込年収」は、どれも年収として扱われるが、
  出どころと信頼度が違う。抽出結果には、どの書類のどの欄から取ったかを必ず残す
- **「年分」と「年度」を混同しない。** 源泉徴収票や確定申告書は「令和7年分」
  (2025年1〜12月の所得)。課税証明書や住民税決定通知書は「令和8年度」で、中身は
  前年(2025年)の所得。比較するときは所得の年(`incomeYear`)で揃える
- **収入と所得は別物。** 「収入」は額面、「所得」は控除後(例: 給与収入580万円 →
  給与所得420万円)。差分の比較では、同じ種類の値どうしを比べる
- **金額は円単位の整数で持つ。** 「万円」「千円」の単位の欄は、抽出時に円へ換算する
- **日付は西暦の ISO 形式(`YYYY-MM-DD`)で持つ。** 和暦からの変換は
  [references/normalization.md](references/normalization.md) の規則に従う
- **自動抽出の結果は、人による確認が前提。** 自信のない値は低い信頼度で返し、
  空欄や読み取れない欄を推測で埋めない

## 個人情報の扱い

- リポジトリに入れてよいのは、架空のダミーデータだけ。氏名・住所・会社名は
  `scripts/generate-samples/people.ts` のように、「見本県」「サンプル商事」など
  明らかに架空と分かるものにし、電話番号は `000` 始まりにする
- 実在の書類の画像や内容を、テスト・コメント・コミットメッセージ・Issueに書かない
- 抽出結果をログやエラーメッセージにそのまま出さない(欄名だけ出す)
