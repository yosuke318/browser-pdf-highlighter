# TypeScriptで書く

このリポジトリのコードはすべてTypeScriptで書く。JavaScript・Pythonなど別の言語で
書きたくなったときも、まずTypeScriptで書けないか考える。

## ルール

- 新規ファイルは `.ts`(UIコンポーネントなら `.tsx`)にする。`.js` / `.mjs` / `.cjs` は
  ツールの設定ファイルなど、TypeScriptが使えない場合だけにする
- `tsconfig.json` は `"strict": true` を前提にする
- `any` は使わない。型が不明な外部データは `unknown` で受けて、型ガードで絞り込む
- pdf.js・tesseract.js などのライブラリは、同梱またはDefinitelyTypedの型定義を使う。
  型定義がないものは `src/types/` に最小限の `.d.ts` を書く
- 書類定義ファイル(抽出ルール)も、型チェックが効くようにTypeScriptの型(またはスキーマ
  から型を生成する方法)で表す
- 使い捨ての調査用スクリプトもTypeScriptで書く(`tsx` などで実行する)
- コメントには造語を使わず、一般的な用語で書く(例: 「サーチャブルPDF」「文字化け」
  「バウンディングボックス」など、読み手が検索して意味が分かる言葉)

## 書き終えたら

- 型チェック(`tsc --noEmit`、またはプロジェクトの `typecheck` スクリプト)を実行し、
  エラーが0件であることを確認してから完了と報告する
- 実行できなかった場合は、そのことを明記する
